RPG::SE

The data class for SE. This class has functionality for playing itself using an Audio module.

Superclass

  • RPG::AudioFile

Referrers

  • RPG::Animation::Timing
  • RPG::System
  • RPG::EventCommand
  • RPG::MoveCommand

Class Method

RPG::SE.stop

Stops SE playback.

Method

play

Starts the SE playback.

Definition

class RPG::SE < RPG::AudioFile
  def play
    unless @name.empty?
      Audio.se_play('Audio/SE/' + @name, @volume, @pitch)
    end
  end
  def self.stop
    Audio.se_stop
  end
end
