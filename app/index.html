About Comments

The comment system on this site is powered by Giscus, an open-source, secure tool that uses GitHub Discussions as a database. To comment or interact on pages, simply sign in with your GitHub account.

New comments appear in this general activity feed in about 2 to 3 minutes after being posted.

If new comments do not appear, please press Ctrl + F5 (or Cmd + Shift + R on Mac) to clear your browser cache.
